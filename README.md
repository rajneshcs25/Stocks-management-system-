STOCK MANAGEMENT SYSTEM - JAVA PROJECT

Project technology:
- Java
- Java Swing (Graphical User Interface)
- JDBC
- MySQL

Included files:
1. StockManagementSystem.java - Main Java program
2. schema.sql - Creates the database and products table

FEATURES
- Add a new product
- View all products
- Update product details
- Delete a product
- Display a stock report (product count, total units and stock value)

SETUP INSTRUCTIONS
1. Install JDK and MySQL.
2. Open MySQL Workbench or the MySQL command line.
3. Run the complete schema.sql file.
4. Open StockManagementSystem.java in an IDE such as NetBeans, Eclipse or IntelliJ.
5. Add MySQL Connector/J to the project's Libraries / Build Path.
6. In StockManagementSystem.java, change:
       DB_USER = "root";
       DB_PASSWORD = "your_password";
   to your own local MySQL username and password.
7. Run StockManagementSystem.java.

IMPORTANT
- Keep MySQL running while using the program.
- The database name must be stock_management.
- This is a beginner-friendly academic project starter. It uses a local database.
- Do not upload or share your real database password.
